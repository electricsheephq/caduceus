# AGENTS.md

Guidance for AI coding agents, and for people, working in this repository.

## What this is

Caduceus: Personalized Health & DNA AI is a standalone Hermes Agent plugin. It keeps a private SQLite vault of the user's DNA
raw data, Promethease report, Apple Health export and health records on their own machine. Four tools search it, look up
genotypes and gene–drug evidence, compute trends, and import and capture data. A research watch looks for new studies about
the user's genes.

## Layout

- `plugin.yaml`: manifest, compatibility and settings schema.
- `__init__.py` and `caduceus/registration.py`: plugin loading. Registration does no I/O.
- `caduceus/tools.py`: the four tool schemas and handlers, and `/caduceus`.
- `caduceus/core/`: storage, provenance, search, the privacy policy and background jobs. Shared by everything else.
- `caduceus/genome/`: DNA raw-data importers, genotype lookup, the Promethease decoder and the rebuilt variant report.
- `caduceus/health/`: the Apple Health importer, FHIR records and trends.
- `caduceus/knowledge/`: the curated gene–drug knowledge pack.
- `caduceus/research/`: the research watch (Europe PMC, NCBI).
- `caduceus/demo/`: the synthetic demo persona behind `/caduceus demo`; the tests use it too (`tests/synth/` re-exports it).
- `skills/`: bundled skills (setup, guide, research, report-problem).
- `docs/contracts.md`: every module's frozen function signatures. **Read it before changing a module.**
- `docs/formats/`: notes on the input formats.
- `tests/`: unit tests (network blocked, synthetic data only); `tests/integration/`, run against a real Hermes loader.

## Setup and checks

Python 3.11 or newer, standard library only.

```bash
python -m pip install pytest
python -m pytest
```

## Rules

- **Standard library only.** No new dependencies, no `pyproject.toml`, no build step.
- **Relative imports only inside `caduceus/`.** Hermes loads the plugin under its own module name.
- **No real personal data, ever.**
  - Every fixture is synthetic and generated by code at test time (`caduceus/demo/`, re-exported by `tests/synth/`).
  - Never commit a binary blob or a file over 1 MB, a real DNA file, a real Apple Health export, or a real report.
  - Never commit text copied from SNPedia or from any real report.
- **No secrets** and no literal `token=`, `api_key=` or `secret=` values.
- **Untrusted input.** Every input file is untrusted.
  - Refuse zip path traversal, XML entity declarations and inflate bombs.
  - Never execute or render scripts embedded in input files.
- **Writes:** inside `write_txn`, with natural keys (`INSERT OR IGNORE` or upserts), so re-imports are no-ops and interrupted imports resume without duplicates.
- **Privacy:** the tools must filter what they show through `core/policy.allowed`. Never send genotypes over the network.
- **Health statements are information with limits, never recommendations.** Don't overstate small genetic effects.
- **Tests:** they never use the network or a real `HERMES_HOME`. Real-file checks are marked `private` and run only locally.
- **Agents:** in a change, don't bump versions, tag, or edit the CHANGELOG release headings. The maintainer's release step does that.
